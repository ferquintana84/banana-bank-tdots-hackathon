  Converting the recording to submission/demo.mp4

  ffmpeg is already installed on this Mac (/opt/homebrew/bin/ffmpeg); nothing
  needs installing. From the project folder:

  ffmpeg -i ~/Desktop/grabacion.mov -c:v libx264 -crf 26 -preset medium -pix_fmt

  - Replace the input path with wherever macOS saved your recording.
  - -crf 26 sets quality against size: a lower number is sharper and larger. I
    have not run this on your recording, so check that small text is readable;
    if not, try 23.
  - scale=-2:1080 shrinks a Retina recording to 1080 pixels tall, which is the
    main saving. Remove it if text becomes hard to read.
  - Fallback without ffmpeg: QuickTime Player → File → Export As → 1080p. It
    writes a .mov; renaming is not a conversion, so prefer the command above.
